# Dokploy Practica

Aplicacion web de prueba desarrollada con Node.js y Express.js para la practica de Administracion de Infraestructura de TI.

## Requisitos

- Node.js
- npm

## Instalacion

```bash
npm install
```

## Ejecucion

```bash
npm start
```

## Rutas

- `/`: informacion general de la aplicacion.
- `/salud`: comprobacion del estado del servidor.
