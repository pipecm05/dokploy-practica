# Dokploy Practica

Aplicación web desarrollada con Node.js y Express.js
para la práctica de Administración de Infraestructura de TI.

## Requisitos

- Node.js
- npm

## Instalación

npm install

## Ejecución

npm start

## Rutas disponibles

- `/`: muestra el mensaje principal de la aplicación.
- `/health`: comprueba el estado de funcionamiento.
- `/info`: muestra información de la aplicación y del entorno Node.js.

## Puerto

La aplicación utiliza el puerto definido en la variable
de entorno PORT. Si no se define, utiliza el puerto 3000.
